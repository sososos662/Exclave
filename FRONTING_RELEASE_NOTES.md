# Exclave 0.17.66-fronting.1

## Обновление базы

- Приложение обновлено до стабильного Exclave 0.17.66, ядро — до коммита,
  используемого этим релизом. Доработки WebSocket fronting сохранены в обоих.
- Включены исправления DNS, закрытия соединений, высокой загрузки CPU после
  переключения сети/отключения Hysteria 2 и обновление безопасности сертификатов
  из upstream 0.17.64. Используется Go 1.27.3.

## Изменения форка

- Сохранены поле fronting host, параметр `fh` в ссылках и импорт настроек JSON.
- Устранён конфликт бинарного формата профилей: старый форк и оригинал использовали
  номер 40 для разных WebSocket-структур. Новый формат имеет отдельный маркер;
  читаются старые профили форка и оригинала, включая TLS/REALITY и поля подклассов.
- Исправлены подсчёт записанных байтов при частичной записи, чтение в пустой буфер
  и проверка лимита HTTP-заголовков вместе с уже пришедшими WebSocket-данными.
- Добавлены тесты миграции профилей, полного WebSocket-подключения с fronting,
  обычного WS и WSS. Fronting по-прежнему применяется **только к plaintext WS**;
  он не является TLS domain fronting и не добавляет шифрование транспорту.
- Сохранены английский/русский интерфейс и необходимые geoip/geosite assets.
- Релизный тег теперь привязан к коммиту сборки; APK сопровождаются SHA-256.

## Перед установкой

- **Сделайте резервную копию профилей и настроек.** Новая сборка использует тот же
  package ID и настроенный в репозитории ключ подписи, с увеличенным versionCode.
- Обычная версия требует **Android 7.0+**. Для Android 5.0–6.0 используйте `legacy`.
- Upstream изменил реализацию REALITY по умолчанию и ALPN для V2Ray QUIC. Для
  нестандартных конфигураций проверьте эти параметры; если нужен старый QUIC ALPN,
  задайте `h2` и `http/1.1` явно. Новый маркер формата не предназначен для отката
  базы данных в оригинальное приложение: переносите профили ссылками/JSON.
- Проверки с локальным тестовым сервером не доказывают работу обхода DPI в сети
  конкретного оператора. На первом релизе новой базы необходима проверка на устройстве.
